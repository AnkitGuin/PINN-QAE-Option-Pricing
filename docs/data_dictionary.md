# Data Dictionary

All datasets used in this project are synthetic (generated by
`experiments/generate_synthetic.py` / `src/data/synthetic_generator.py`) except
for the conditional real-data path of Experiment 3, which is **not executed**
(no eligible provider data is accessible in this environment; see
`results/experiment_3/status.json` and `docs/limitations.md`).

## Observation-level table (`data/synthetic/*_observations.csv`)

One row per listed option contract observation.

| Column | Type | Description |
|---|---|---|
| `timestamp` | datetime (UTC) | Observation date (business days) |
| `underlying` | str | Underlying identifier (`SYNTH`) |
| `spot` | float | Underlying spot price at `timestamp` (synthetic GBM-like path, independent of the pricing volatility schedule) |
| `strike` | float | Option strike |
| `expiration` | datetime | Option expiration date |
| `tau` | float | Year fraction to expiration (ACT/365.25) |
| `option_type` | str | Always `call` (European) |
| `exercise_style` | str | Always `european` |
| `currency` | str | `USD` |
| `rate` | float | Risk-free rate for [t, T] (from the rate schedule; constant in all scenarios) |
| `bid`, `ask` | float | Synthetic quotes centred on the mid (`market_price`); spread is zero in the default synthetic config (no quote noise) |
| `market_price` | float | Observed premium: `true_price + noise` (noise = 0 in clean scenarios) |
| `implied_volatility` | float | IV inverted from `market_price` (target-derived; **never a model input**) |
| `volume`, `open_interest` | int | Placeholder liquidity fields (synthetic constant) |
| `true_price` | float | **Synthetic only.** Analytical Black–Scholes price at the true integrated volatility |
| `true_sigma` | float | **Synthetic only.** Effective (integrated) volatility σ_eff = sqrt(A(t,T)/τ) with A the exact integrated variance of the schedule over [t,T] |
| `true_sigma_instantaneous` | float | **Synthetic only.** Schedule value at `timestamp` |
| `observed_price` | float | Alias of `market_price` for clarity in analysis |
| `noise` | float | **Synthetic only.** `market_price − true_price` |
| `regime` | str | **Synthetic only.** Volatility regime label (e.g. `low`, `high`) |
| `source` | str | Provenance tag (`synthetic:<scenario>`) |
| `quality_flag` | int | 0 = pass; bitmask of issues otherwise |

### Leakage rules (enforced in code and by `tests/test_no_leakage.py`)

- `SYNTHETIC_ONLY_FIELDS = [true_price, true_sigma, true_sigma_instantaneous, noise, regime]`
  are never model inputs or calibration targets; they exist for recovery
  assessment and evaluation only.
- `MODEL_INPUT_FIELDS = [spot, strike, tau, rate]` — the only legitimate
  pricing inputs.
- `market_price` is the calibration **target** (never an input feature);
  `implied_volatility` (a target-derived quantity) is never an input.
- Evaluation uses `true_price` as the reference **only after** predictions
  are produced (see `evaluate_block_with_sigma`), and is checked to be
  invariant to perturbation of all other synthetic-only fields.

## Scenario configurations (`configs/synthetic/*.yaml`)

| Scenario | Volatility schedule | Noise | Grid |
|---|---|---|---|
| `constant` | σ = 0.20 flat | none | 9 moneyness 0.85–1.15 × 5 maturities |
| `gradual_change` | 0.18 → 0.32 linearly | none | same |
| `abrupt_change` | 0.20 / 0.35 / 0.18 (40 business days each) | none | same |
| `noise_sparse` | σ = 0.20 flat | relative Gaussian, 2% of price | 5 moneyness 0.90–1.10 × 3 maturities |

Experiment-2 conditions map onto these as: `constant_clean` (constant),
`constant_noise` (constant + 2% noise), `constant_sparse` (constant + sparse
grid), `constant_noise_sparse` (noise_sparse), `gradual_change`,
`abrupt_change`. Moneyness grid, maturities, noise mode and magnitude, dates,
strikes, rates and seeds are all configuration-driven (no hard-coded values).

## Result artifacts

- `results/experiment_N/{config.json, manifest.json, summary.json}` —
  configuration used, environment/seed manifest, machine-readable results.
- `results/experiment_2/{condition}__seed{seed}/` — per-run artifacts:
  `metrics.json` (run summary), `block_table.csv` (per-method, per-block
  evaluation), `sigma_history.csv` (rolling estimates + references),
  `training_history_first_window.csv` (PINN loss trajectory, first window).
- `results/experiment_4/` — `qae_main.csv` (error decomposition rows),
  `sweep_m.csv`, `sweep_n.csv`, `mc_convergence.csv`, `resources.json`.
- `figures/figures_manifest.json` — figure list with descriptions and data
  sources.
